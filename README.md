# Squizzotti's Diet

Web app per pianificare i pasti della settimana e generare la lista della spesa.

- Frontend statico pubblicato con GitHub Pages.
- Dati (piani alimentari, scelte settimanali, spesa) su Supabase, accessibili solo agli utenti autenticati.

Questo repository è pubblico: non contiene dati personali né chiavi segrete.
